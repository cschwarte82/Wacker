# TrainerRadar – Wacker Mecklenbeck

Web-App für Handy und Laptop: Testtage, Spielbewertungen, Stärkenprofile, Ranglisten und Aufstellungsvorschläge für eine U10-Mannschaft.

## Installieren
- **iPhone (Safari):** https://cschwarte82.github.io/wacker/ öffnen → Teilen-Symbol → „Zum Home-Bildschirm“.
- **Android (Chrome):** Link öffnen → Menü ⋮ → „App installieren“.

## Datenschutz
Alle Spielerdaten bleiben auf dem eigenen Gerät. Dieses Repository enthält nur den Programmcode, keine Daten.

## Daten sichern
Kader → Datensicherung → „Sicherung speichern“ (iPhone: „In Dateien sichern“ → iCloud Drive). Wiederherstellen über „Sicherung einlesen“.
